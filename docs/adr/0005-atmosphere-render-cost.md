# ADR-0005：氛围层禁止对全屏图层做 transform，逐帧只改 transform/opacity

- 状态：已接受
- 日期：2026-09-21
- 相关：[AtmosphereLayer.tsx](../../app/create-video/src/components/AtmosphereLayer.tsx)，[呈现层约束](../design/story-workflow.md)

## 背景

为成片加入氛围层（光感扫动 + 悬浮尘埃 + 暗角）后，实测渲染成本从旧版基线约 22.3 秒/300 帧涨到 63 秒/300 帧。用逐项关闭法归因（同一 300 帧输入、同一素材）：

| 配置 | 300 帧耗时 |
|---|---|
| 完整实现（光扫 transform + 尘埃 left/top + 暗角） | 63s |
| 关闭整个氛围层 | 22s |
| 只关尘埃（留光扫与暗角） | 23s |
| 只关光扫（留尘埃与暗角） | 21s |

单个成分都不贵，**两个成分同时存在才炸**：对全屏渐变层做 `transform` 平移需要重新光栅化整层，而用 `left/top` 定位的 16 个微粒每帧触发布局，两者叠加后每帧都要重建并合成大图层。

## 决策

1. **不对全屏尺寸的元素做 `transform` 位移**。光感改为静态渐变之上做缓慢 `opacity` 呼吸。
2. **逐帧变化的元素一律用 `transform: translate3d()` 定位**，元素初始 `left/top` 固定为 0；禁止用 `left`/`top`/`margin` 做动画。
3. 静态元素（暗角）保持完全静态，不参与每帧变化。
4. 微粒数量按视觉需要取下限（当前 14），且位置由 `@remotion/noise` 连续噪声驱动，避免重复与闪烁。
5. 呈现层改动后必须用**定帧区间**测性能：`remotion render … --frames=200-499`，与基线对比后才允许提交。

## 后果

- 正面：优化后拿到交叉溶解、逐句字幕与氛围层，且**定帧对照口径**下成本可接受（300 帧：完整实现 63s → 优化后 26s，无氛围层基线 22s）。
- 代价：放弃了横向扫动的光感（视觉上退化为明暗呼吸）。若将来确需大范围运动光效，应改用离屏预合成或缩小运动元素的覆盖面积，而不是恢复全屏 transform。
- 约束的可测性：切点最低亮度从旧版 20.5–21.6（近黑）提升到 97.6–110.1，可作为回归探针。
