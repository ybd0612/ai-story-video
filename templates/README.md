# 模板目录

A 阶段建立模板边界与按需加载基础；B 阶段提供兼容镜像；C 阶段提供一致性校验；D 阶段完成 SSOT 默认路径切换。现有 `data/` 内容不删除，旧模板入口保留只读兼容。

## 分类

- `workflows/`：工作流定义与阶段契约。
- `story/`：故事结构与脚本模板。
- `style/`：视觉风格与构图偏好。
- `voice/`：语音与旁白偏好。
- `platform/`：平台输出规格。
- `policy/`：安全、审核与内容策略。

现有模板文件保持原路径兼容；新内容应写入分类目录，旧根目录 title/script 仅作为只读兼容入口，不再新增。
