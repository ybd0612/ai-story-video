# 模板目录

A 阶段仅建立模板边界与按需加载基础，不移动或复制现有 `data/` 内容，也不改变生成链路。

## 分类

- `workflows/`：工作流定义与阶段契约。
- `story/`：故事结构与脚本模板。
- `style/`：视觉风格与构图偏好。
- `voice/`：语音与旁白偏好。
- `platform/`：平台输出规格。
- `policy/`：安全、审核与内容策略。

现有模板文件保持原路径兼容；后续迁移需遵循 SSOT 评审流程。

## C 阶段状态

C 阶段已增加旧/新布局的一致性校验、模板 Catalog 路径校验和 context canonical records。校验失败只报告差异，不自动修复、复制或删除。
