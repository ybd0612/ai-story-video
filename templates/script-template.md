## 脚本结构

### 30秒快剪版
```
[0-3秒]  开场钩子（反差/共鸣）
[3-20秒] 核心内容（2-3个点）
[20-27秒] 亮点/反转
[27-30秒] 互动引导
```

### 60秒标准版
```
[0-3秒]   开场钩子
[3-15秒]  铺垫/背景（程序员日常切入）
[15-40秒] 核心内容（3-4个点）
[40-50秒] 高潮/亮点（奶爸反差时刻）
[50-57秒] 总结金句
[57-60秒] 互动引导
```

### 剧情反转版
```
[0-5秒]   制造期待（程序员视角）
[5-25秒]  正常推进（日常带娃）
[25-50秒] 铺垫高潮（意外/崩溃时刻）
[50-57秒] 神转折（暖心结局）
[57-60秒] 金句收尾
```

## 常用场景脚本框架

### 产检记录类
```
[开场] "今天陪老婆来做NT检查，作为程序员我做了攻略..."
[过程] 检查流程 + 紧张心情 + 程序员式分析
[反转] "结果出来那一刻，我哭了"
[结尾] "准爸爸们，产检一定要陪！"
```

### 奶爸日常类
```
[开场] "当程序员遇上带娃..."
[对比] 写代码 vs 带娃的反差
[高光] 崩溃瞬间 or 暖心瞬间
[结尾] 关注我，看程序员奶爸成长记
```

### 孕期知识类
```
[开场] "新手爸爸注意了！这个知识点90%的人不知道"
[内容] 干货分享（建档/产检/准备物品）
[实用] 具体步骤/清单
[结尾] "收藏起来，以后用得上"
```

### 程序员视角类
```
[开场] "作为一个Java程序员，我用写代码的思路来..."
[过程] 把育儿/家务用程序员思维解读
[反转] "没想到老婆比我还卷"
[结尾] "程序员当爸，就是这么硬核"
```
